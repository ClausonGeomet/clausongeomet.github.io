Geometallurgical Drillhole Optimiser

Public synthetic demonstration

Which existing drill-core samples should receive the next round of metallurgical testwork?

The first public demonstration focuses on selecting Bond Ball Work Index (BBWi) laboratory tests from intervals that have already been drilled and assayed.

Follow the evidence from geological domains and routine assays to an auditable testwork shortlist. Explore how budget, available evidence and decision priorities affect the modelled information value of a batch. All example data are synthetic.

Open interactive demo ↗ Read the guided walkthrough ↗

The app opens on Posit Connect Cloud. Start with the default existing-core example, then inspect the selected intervals, recorded costs and predictive checks.

From data to a decision

Start with: known locations, geological domains, routine assays, test costs and available BBWi results.

Explore: candidate testwork selections under cost and resource constraints, with assumptions made explicit.

Interpret: model-conditional information and uncertainty trade-offs, rather than a single universal optimum.

What this demonstration does not establish

A synthetic example is not validation for a mine. This first demonstration is not a validated undrilled-hole planning system, and its uncertainty estimates do not eliminate process variation or laboratory measurement noise.

The public app uses synthetic data and the source repository remains private. Please do not send confidential datasets in an initial enquiry.
